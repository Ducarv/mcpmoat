# Popular MCP servers, the reference list for the typosquat check (rule
# MOAT-T5-001, threat T5). A server name or package that is very close to one
# of these names, but not equal to it, is reported. So is an equal name under
# the runner of another kind, and a docker image under another owner with the
# same last component.
#
# Format: one entry per line, written as kind:name. Lines that start with #
# and empty lines are ignored.
#   - kind is one of npm, pypi or docker (lowercase).
#   - Split at the first colon. The name is everything after it.
#   - The name is the full package name: npm with its scope, the PyPI project
#     name, or the docker image with its registry host (for example
#     ghcr.io/github/github-mcp-server). Docker Hub images such as mcp/fetch
#     have no host.
#   - The name is lowercase. Do not add a version or a tag.
#   - Keep every name at least 5 characters long (runes).
#   - No duplicate (kind, name) pair. The same name may appear under two kinds
#     only if it is a genuine popular server on both registries.
#   - Give every docker entry its own last path component. When two docker
#     entries share one (mcp/fetch and ghcr.io/x/fetch), the namespace squat
#     check skips that name and a squat of either image goes unseen.
# Check the kind against the real registry before you add an entry.
